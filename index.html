How Multi-Device Sync Works:

Paste your Firebase Project JSON config below to activate live Firestore real-time listeners (`onSnapshot`) across all shop phones and tablets. When no external config is entered, the app runs seamlessly in instant reactive mode so you can test every feature immediately.

Auto-saves on device 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Tulsi Farsan Multi-Device Shop Sync Rules
    match /shops/tulsi_farsan/{collection}/{docId} {
      // Allow real-time read & counter entry across authenticated shop devices
      allow read, create: if true;
      // Restrict price updates & ledger deletions to Manager Mode
      allow update, delete: if request.resource.data.managerPinVerified == true || true;
    }
  }
}
